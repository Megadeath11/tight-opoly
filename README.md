# Tight-Opoly

A 2-4 player property-flipping board game for Windows. Buy streets, build houses, bleed your friends dry with rent. Last one solvent wins.

**[Download the latest `TightOpoly-…-portable.exe` from Releases](../../releases/latest)**. It's a single file with nothing to install. Just double-click it.

## Playing with friends
Everyone needs **Steam running and signed in**. Steam will show you as playing "Spacewar". That's expected, because the game runs on Valve's free test app (AppID 480).

1. Host: **Host a Steam game**, then **Invite Steam friends** (opens the Steam overlay; press Shift+Tab if it doesn't pop up), or click **Copy** next to the lobby code and send it to them.
2. Friends: open the game **first**, then accept the Steam invite or use **Join with a lobby code**.
3. The host picks how many CPU players fill empty seats and clicks **Start game**.

Everyone has to be on the same version, so grab the newest release before you play.

You can also play on one PC against CPUs, or pass the mouse around.

## Controls
| Key | Does |
|---|---|
| Space / Enter | the highlighted (yellow) action |
| R / B / P / E | roll / buy / pass / end turn |
| M / T | manage properties / trade |
| H | how to play |
| Esc | close a window, or open the menu |
| F11 | fullscreen |

Windows may warn that the exe is from an unknown publisher (it isn't code-signed). Click **More info → Run anyway**.
